# Antigravity UI — IDE BiDi & Typography Suite

Official companion extension for Google Antigravity IDE:
- Intelligent Right-to-Left (RTL) detection for Chat, Agent, Plan, and Composer
- Vazirmatn Persian/Arabic typography across the entire workspace
- Strict LTR isolation for code blocks, terminal, and monospace text
- Status Bar direction switch and `Ctrl+Alt+R` hotkey
- Fully reversible with clean uninstall support
